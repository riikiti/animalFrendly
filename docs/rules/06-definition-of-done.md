# Definition of Done

[← к оглавлению правил](../RULES.md)

Задача (фича/модуль) считается завершённой, только если выполнено всё применимое из
списка:

- [ ] Поведение и структуры данных описаны в `docs/plan/*.md` / `docs/database/*.md`
      **до** того, как код смёржен (см. [`00-general.md`](./00-general.md)).
- [ ] Domain-логика покрыта unit-тестами без БД/HTTP.
- [ ] Use case'ы покрыты тестами с замоканными зависимостями.
- [ ] HTTP-эндпоинты покрыты Feature-тестами (успешный путь + минимум один негативный).
- [ ] Для денежных операций — обязательные сценарии из
      [`04-payments-escrow.md`](./04-payments-escrow.md) пройдены.
- [ ] Frontend: компонент/страница покрыты хотя бы одним component-тестом; если это часть
      критичного флоу (см. [`05-testing.md`](./05-testing.md)) — добавлен/обновлён E2E.
- [ ] Mobile: экран визуально и по флоу соответствует мобильной версии сайта (сверено с
      [`../mockups/mockup.html`](../mockups/mockup.html) или актуальным состоянием фронта).
- [ ] Секреты не хардкожены, `.env.example` обновлён при необходимости.
- [ ] Статический анализ и линтеры проходят без новых предупреждений.
- [ ] Для UI-изменений — фича руками проверена в браузере/на эмуляторе (happy path + хотя
      бы один edge case), а не только «тесты зелёные».
