# Backend (Laravel, DDD)

[← к оглавлению правил](../RULES.md) · структура — [`../plan/04-backend-structure.md`](../plan/04-backend-structure.md)

## Слои

- **Domain** — чистый PHP, ноль зависимостей от Illuminate/Eloquent/фасадов. Здесь живут
  правила вроде «сделка не может перейти из `completed` обратно в `paid_escrow`».
  Тестируется без БД и HTTP.
- **Application** — use case'ы: один класс = одно действие (`ConfirmDealByBuyer`,
  `PublishListing`), оркестрирует Domain + интерфейсы репозиториев. Никакой бизнес-логики
  сверх оркестрации — она в Domain.
- **Infrastructure** — Eloquent-модели, реализации репозиториев, адаптеры внешних API
  (ЮKassa-клиент, FCM-клиент, S3). Реализует интерфейсы, объявленные в Domain.
- **Presentation** — контроллеры, FormRequest, API Resources, роуты. Контроллер только:
  провалидировать → вызвать use case → вернуть Resource. Никакой логики в контроллере.

## Правила модульности

- Модуль не импортирует Eloquent-модели другого модуля напрямую. Межмодульная связь —
  через доменные события (`DomainEvent` + листенер в другом модуле) или явный
  Application-контракт (интерфейс в одном модуле, реализация может знать про другой модуль
  только на уровне Infrastructure/Provider).
- Список модулей и их зона ответственности — [`../plan/01-modules.md`](../plan/01-modules.md).

## Конкретные требования

- Деньги — `Shared\Domain\ValueObjects\Money` (целые копейки), никогда `float`.
- Все таймстемпы — UTC.
- Многошаговые операции с записью — в транзакции БД (`DB::transaction`), особенно смена
  статуса сделки + запись в историю статусов.
- Ответы API — только через API Resources, Eloquent-модели наружу не отдаются.
- Авторизация — через Laravel Policy/Gate, не через `if ($user->role === ...)` в
  контроллере.
- Тяжёлые/внешние вызовы (обработка вебхука ЮKassa, отправка push, email) — через очередь
  (Job), не синхронно в HTTP-запросе.
- API версионируется: `/api/v1/...`.
- Статический анализ: PHPStan (Larastan) на высоком уровне, Laravel Pint для стиля — оба
  обязательны в CI, PR с ошибками анализатора не мержится.
- Логи — структурированный JSON в stdout/stderr, никогда в локальный файл контейнера;
  формат, корреляция запросов и что запрещено логировать (секреты, ПД без маскирования) —
  [`../plan/13-logging.md`](../plan/13-logging.md).
