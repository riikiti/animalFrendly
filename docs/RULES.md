# AnimalFriendly — правила разработки (оглавление)

> Эти правила обязательны при написании и правке кода в каждом из разделов проекта.
> Начните с [`rules/00-general.md`](./rules/00-general.md) — там главное правило
> «план → код» и требования к секретам/`.env`, которые действуют везде.

- [`rules/01-backend.md`](./rules/01-backend.md) — Laravel/DDD: слои, модульность, требования к коду
- [`rules/02-frontend.md`](./rules/02-frontend.md) — Vue3/FSD: слои, состояние, стили, пэйволл
- [`rules/03-mobile.md`](./rules/03-mobile.md) — Kotlin Multiplatform: shared vs platform, паритет с сайтом
- [`rules/04-payments-escrow.md`](./rules/04-payments-escrow.md) — ЮKassa, идемпотентность, эскроу, авто-подтверждение
- [`rules/05-testing.md`](./rules/05-testing.md) — пирамида тестов по всем трём платформам
- [`rules/06-definition-of-done.md`](./rules/06-definition-of-done.md) — чек-лист готовности задачи
- [`rules/07-infrastructure.md`](./rules/07-infrastructure.md) — единый бэкенд/БД, образы, секреты, миграции, K8s-приоритет, CI/CD после основного кода
