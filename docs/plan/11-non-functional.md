# Нефункциональные требования

[← к оглавлению плана](../PLAN.md)

- **Персональные данные (152-ФЗ):** согласие на обработку при регистрации, хранение
  документов верификации приюта/заводчика с ограниченным доступом, логирование доступа.
- **Безопасность:** OWASP Top 10, rate-limiting на auth/матчинг API, антифрод на маркетплейсе
  (лимиты на новые аккаунты продавцов до верификации).
- **Масштабируемость:** свайпы/чат — потенциально высоконагруженные, вынесены на Redis
  (лента кандидатов, presence), очереди для уведомлений и вебхуков.
- **Локализация:** RU на старте, архитектура строк/форматов дат — с заделом под i18n.
- **Наблюдаемость:** структурные логи, Laravel Telescope/Horizon в dev, метрики очередей и
  платежей в проде.
