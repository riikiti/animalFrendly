# Бизнес-флоу: свайп/мэтч и усыновление через приют

[← к оглавлению плана](../PLAN.md)

## Свайп / мэтч

1. Пользователь свайпает анкету питомца (`like` / `dislike` / `super_like`).
2. Если обе стороны поставили `like` друг другу → создаётся `match`, открывается чат
   (модуль `Chat`).
3. `super_like` и «буст анкеты» — лимитированные ресурсы, расход зависит от тарифа подписки
   (см. [`09-flow-subscriptions.md`](./09-flow-subscriptions.md)).
4. Свайпнутые анкеты не показываются повторно (кроме сброса лимита раз в сутки для free-тарифа).

Модули: `Matching`, `Profile`, `Chat`, `Subscription`. Таблицы — `database/03-matching-chat.md`.

## Усыновление через приют

1. Приют (после верификации модератором) публикует карточку животного (`shelter_animal`).
2. Пользователь отправляет заявку на усыновление (`adoption_request`) с анкетой/сообщением.
3. Приют рассматривает заявку: `pending → approved/rejected`, переписка через тот же
   Chat-модуль.
4. При `approved` карточка животного переходит в статус `reserved`, затем `adopted`.
5. Денежных операций в этом флоу может не быть (либо опциональный донат приюту — без эскроу,
   отдельная простая оплата через ЮKassa без удержания).

Модули: `Shelter`, `Moderation` (верификация), `Chat`. Таблицы — `database/04-shelter.md`.
