## Концепция

AnimalFriendly — платформа для владельцев животных, три сценария:

1. **Знакомства/мэтчинг** (Tinder-like) — владельцы находят других животных/владельцев рядом
   (дружба, вязка, выгул) через свайпы анкет питомцев.
2. **Приюты** — верифицированные организации публикуют животных на пристройство, ведут
   заявки на усыновление.
3. **Маркетплейс** — заводчики продают щенков/котят/etc. Сервис берёт **5% комиссии**,
   удерживает деньги на эскроу до подтверждения сделки обеими сторонами или автоматически
   через 7 дней.

Плюс монетизация через **подписки** (уровни по образцу Tinder Gold/Platinum и Twinby).

Рынок — Россия: оплата через **ЮKassa**, соответствие 152-ФЗ обязательно.

Подробности бизнес-флоу: [`07-flow-matching-shelter.md`](./07-flow-matching-shelter.md),
[`08-flow-marketplace-escrow.md`](./08-flow-marketplace-escrow.md),

## Роли пользователей

| Роль | Описание |
|---|---|
| Гость | Просмотр публичных анкет/маркетплейса ограниченно, без свайпов/чата |
| Пользователь (владелец) | Анкеты питомцев, свайпы, мэтчи, чат, покупки, заявки в приюты |
| Заводчик (verified) | Роль пользователя + может создавать листинги на продажу |
| Приют (organization) | Верифицированный юрлицо/НКО-аккаунт: карточки на пристройство, заявки |
| Модератор | Проверка контента, жалоб, верификация заводчиков/приютов |
| Админ | Полный доступ, тарифы/комиссии, финансовые операции |

Верификация заводчика и приюта — ручная модерация (документы/фото), очередь в админке.

## Дорожная карта (фазы)

| Фаза | Содержание |
|---|---|
| 0 | Планирование, макет, правила — **текущая** |
| 1 | Инфраструктура, Identity, Profile, Catalog |
| 2 | Matching (свайпы/мэтчи) + Chat |
| 3 | Shelter: верификация, карточки животных, заявки на усыновление |
| 4 | Marketplace + Payment: листинги, сделки, эскроу, интеграция ЮKassa |
| 5 | Subscription: тарифы, paywall, автопродление |
| 6 | Мобильное приложение (Android): паритет по функциям и дизайну с мобильным сайтом |
| 7 | Notification, Moderation, Admin-панель, полировка, нагрузочное тестирование |
| 8 | iOS-версия (переиспользование `shared`-модуля KMP) |

## Открытые вопросы (не блокируют старт, решить до соответствующей фазы)

- Юридическая модель приютов (НКО без продаж) vs заводчиков (ИП/самозанятые) — влияет на
  документы для верификации и на форму чека ЮKassa (54-ФЗ).
- Способ решения споров (`disputed`) — на первом этапе ручная модерация, критерии решения.
- Гео-механика подбора (радиус) — источник геоданных (GPS с согласия / город из профиля).
