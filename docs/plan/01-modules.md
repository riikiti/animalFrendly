# Функциональные модули (bounded contexts)

[← к оглавлению плана](../PLAN.md)

Каждый модуль — отдельный bounded context в DDD-смысле, со своей моделью и словарём.
Общение между модулями — только через доменные события или явные Application-контракты
(никогда через прямой импорт Eloquent-моделей чужого модуля). Один и тот же список модулей
используется как структура папок бэкенда — см. [`04-backend-structure.md`](./04-backend-structure.md).

1. **Identity** — регистрация, аутентификация, роли/права, верификация аккаунтов
2. **Profile** — профиль пользователя + анкеты питомцев (вид, порода, фото, здоровье, прививки)
3. **Catalog** — справочник видов животных и пород (иерархия), атрибуты породы
4. **Matching** — свайпы, лайки/дизлайки/супер-лайки, алгоритм подбора, мэтчи
5. **Chat** — сообщения между matched пользователями, реалтайм (WebSocket)
6. **Shelter** — профили приютов, верификация, карточки животных на пристройство, заявки на усыновление
7. **Marketplace** — листинги на продажу, сделки, состояние сделки, споры
8. **Payment** — интеграция с ЮKassa, эскроу-логика, комиссия, выплаты, вебхуки
9. **Subscription** — тарифные планы, фичи по подписке, биллинг, автопродление
10. **Notification** — push (FCM), email, in-app уведомления
11. **Moderation** — жалобы, баны, ревью контента, рейтинги/отзывы после сделок
12. **Media** — загрузка/хранение фото и видео (S3-совместимое хранилище)
13. **Search** — поиск и фильтрация (вид/порода/локация/цена) для мэтчинга и маркетплейса
14. **Admin** — панель администратора/поддержки, тонкий слой поверх остальных модулей
